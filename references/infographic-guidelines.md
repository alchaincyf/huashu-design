# Infographic Guidelines（信息图/可视化排版规范）

信息图的核心是「信息」+「设计」——两者都需要，缺一不可。

## 适用场景

- 项目路线图：时间线 + 里程碑 + 进度
- 功能矩阵：产品/功能对比网格表
- 对比表：A vs B 多维度对比
- 技术路线展示：模块 + 流程 + 依赖关系
- 展示型 infographic：非论文级的数据可视化排版

## 设计原则

### 1. 信息先于装饰

每块数据/内容必须服务叙事。问自己：
- 去掉这个元素，信息是否受损？
- 这个装饰是在帮助理解，还是在制造噪音？

### 2. 视觉层级

| 层级 | 视觉处理 |
|------|---------|
| 标题/核心数据 | 最大字号，display 字体 |
| 分类标签 | 二级字号，颜色区分 |
| 说明文字 | 三级字号，不抢视觉 |
| 来源/脚注 | 最小字号，放在底部 |

### 3. 网格与对齐

- 用 CSS Grid 做精准分栏
- 同类信息保持统一对齐
- 分栏宽度有比例（黄金比例 / 3:2 / 1:1）

### 4. 对比结构

- 横向对比：每列一个项目，每行一个维度
- 纵向对比：突出某个维度的差异
- 使用颜色/图标辅助，但不要依赖颜色作为唯一信息载体

## 数据诚实

- 缺真实数据 → 标注「待提供」
- 估算数据 → 标注「估算值」
- 百分比必须有基数 → "85%（N=200）」不写"85%的人..."
- 不编造假统计数字来填空隙

## 禁止

- ❌ 纯装饰性图标填充
- ❌ 无意义的大号数字装饰
- ❌ 没有数据不画图（柱状图/饼图必须有数据支撑）
- ❌ 科研级实验数据图、统计显著性图（由 research-figure 负责）
