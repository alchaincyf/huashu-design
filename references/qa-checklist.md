# QA Checklist（交付前自检清单）

从 SKILL.md §5 展开，每条附带检查标准。

## 1. Filler 检查

- [ ] 页面是否有无实际内容的大块图片/装饰？
- [ ] 是否有纯装饰性的 stats/quotes？
- [ ] 每个元素都有理由存在吗？

## 2. AI Slop 检查

- [ ] 是否有紫色渐变背景？（除非品牌用）
- [ ] 是否有 emoji 作为功能图标？（除非品牌风格）
- [ ] 是否有圆角卡片 + 左彩色 border accent？（除非要求）
- [ ] 是否有 SVG 画的人脸/场景/物品？
- [ ] 是否有 Inter/Roboto 作为 display 字体？（除非品牌用）
- [ ] 是否有默认深蓝底 + 霓虹 glow 的「GitHub dark」偷懒解？

## 3. 品牌资产检查

- [ ] 设计中出现的所有品牌/产品 logo 是否真实？
- [ ] 产品图是否为真实产品图（不是 CSS 剪影）？
- [ ] 色值是否从真实品牌资产中提取？
- [ ] 使用了 placeholder？是否明确标注了「待补充」？

## 4. 排版/溢出检查

- [ ] 所有文字都在容器内，没有溢出？
- [ ] 字号 >= 24px（deck/幻灯片场景）？
- [ ] 标题/正文/标注有明确字号阶梯？
- [ ] 中文排印使用「」、英文排版使用 en dash / em dash？

## 5. 视觉层级检查

- [ ] 视线第一时间落在最重要的元素上？
- [ ] 辅助信息不抢主体信息？
- [ ] 品牌信息在合理位置（不抢核心视觉）？

## 6. 可编辑/可复用检查

- [ ] HTML 源码整洁（CSS 变量化、无硬编码色值）？
- [ ] 文件命名描述性？
- [ ] 如果拆了多文件，README 或页面注释说明怎么打开？

## Decision Ownership 检查

- [ ] 我是否擅自决定了用户应该选择的风格方向？
- [ ] 我是否擅自选择了品牌调性、内容优先级或交付格式？
- [ ] 所有关键假设是否已经明确写出并告知用户？
- [ ] 如果用户没有确认方向，我是否只做了低成本 preview，而不是完整大成品？

## 7. 边界检查

- [ ] 这个任务是不是真的属于 product-visual-design？（不是工程图？不是科研图？）
- [ ] 有没有误把产品视觉当工程图/论文图处理？
