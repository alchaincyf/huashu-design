# 产品视觉表达模式

产品视觉图和普通网页设计的区别：产品视觉图以「展示」为目的，不是以「交互」为目的。

## 核心原则

### 1. 主视觉优先

每张产品图只有一个视觉中心。观众视线应先落在这里，再流向辅助信息。

- 产品图：产品渲染/真图最大，说明文字次之
- 概念图：核心概念居中或居左上，辅助说明围绕
- 封面图：标题 + 主视觉 + 品牌色点缀，三要素

### 2. 信息层级

产品视觉图通常包含三层信息：

1. **主体**（产品、概念、标题）——占画面 40-60%
2. **关键说明**（特性标签、数据、一句话卖点）——辅助，不抢主体
3. **品牌信息**（logo、品牌名、底部说明）——最次要层级

### 3. 留白与密度

- 产品展示图：密度适中，有呼吸空间
- 功能对比图：密度较高，但每列/每行视觉边界清晰
- 架构展示图：模块化处理，每组一个视觉单元

### 4. 对比结构

两种常用布局：

- **左右对比**：旧 vs 新、前 vs 后、A vs B
- **矩阵排列**：多产品/多功能同屏展示

### 5. 排版节奏

- 标题：display 字体，字重 >= 600
- 副标题/说明：body 字体，字重 400
- 标签/数据：mono 字体或与 body 区分字重
- 不要所有文字同一字号、同一字重

## 常见类型参考

| 类型 | 典型尺寸 | 视觉重点 |
|------|---------|---------|
| 项目封面图 | 16:9 / 1200×630 | title + visual + brand |
| 功能介绍图 | 4:3 / 16:9 | product + feature callouts |
| 概念图 | 自由 | core concept + supporting context |
| hero section | 1440×800+ | headline + subhead + CTA |
| 架构展示图 | 16:9 | modular components + flow |
