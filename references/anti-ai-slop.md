# 反 AI Slop 规则

AI slop = AI 训练语料中「视觉最大公约数」——所有品牌混合后的平均值，等于稀释任何单一品牌的识别度。

## 核心要规避的

| 元素 | 为什么是 slop | 可以破例的情况 |
|------|-------------|---------------|
| 紫色渐变科技感 | AI 万能科技感公式 | 品牌本身用紫渐变（如 Linear） |
| emoji 作图标 | 「不够专业就用 emoji 凑」 | 品牌本身用（如 Notion），或儿童向产品 |
| 圆角卡片 + 左彩色 border accent | 2020-2024 Material/Tailwind 烂大街 | 用户明确要求，或品牌 spec 保留 |
| SVG 画人脸/场景/物品 | AI 画的 SVG 永远五官错位 | 几乎没有——有图用真图，没图用 placeholder |
| CSS 剪影冒充真实产品图 | 没有品牌识别度 | 几乎没有——先走品牌资产协议 |
| Inter/Roboto 作 display | 太常见，看不出品牌特点 | 品牌 spec 明确用 |
| 每个 bullet 都配 icon | 装饰性填充 | 图标承载差异化信息时 |

## 正向做什么

- ✅ `text-wrap: pretty` + CSS Grid + 排版细节
- ✅ 用 `oklch()` 或 spec 已有的色，不凭空发明新颜色
- ✅ 文案用「」引号不用 ""（中文排印规范）
- ✅ 一个细节做到 120%，其他做到 80%
- ✅ 配图优先真实素材（Unsplash / Wikimedia），其次诚实 placeholder

## 判断边界

「品牌本身用」是唯一合法的破例理由。如果品牌 spec 写明用紫渐变，那就用——此时不是 slop，是品牌签名。

不要在「反 slop」的名义下禁掉有作者意图的暗色/大胆设计。反 slop 反的是**无品牌意图的默认选择**，不是反风格。
