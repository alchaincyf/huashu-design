# 品牌资产协议（精简版）

涉及真实品牌/产品时执行。目标：确保设计中的品牌元素真实可识别。

## 核心原则

真实资产 > CSS 硬画 > 假 logo/假产品图。不编造不存在的品牌元素。

## 精简流程

1. **问**：问用户要 logo / 产品图 / UI 截图 / 色板 / 字体规范
2. **搜官方渠道**：官网 press kit、`svgl` API、`simpleicons`、品牌官网
3. **取真实资产**：下载或 base64 嵌入，不要外链依赖
4. **固化 spec**：写 `brand-spec.md` 记录色值/字体/资产路径/CSS 变量
5. **自检**：设计中出现 logo/产品图/UI 截图了吗？它们真实吗？

## 找不到怎么办

- 商标：诚实 placeholder 并标注「logo 待补充」
- 产品图：诚实 placeholder 并标注「产品图待补充」
- 色值：从官网截图取色或用中性色
- 字体：用开源替代（Inter / Source Serif / Noto 系列）

## 禁止

- ❌ 用 CSS/SVG 画假 logo
- ❌ 用 SVG 剪影代替产品图
- ❌ 编造品牌色值
- ❌ 从视频/截帧取图作为主资产
- ❌ 默认 AI 生成品牌元素
